**Project:** Website Creation for CV Preparation and AI Interview Training
**Project Overview:** NextHire.ai

> The homepage features two side-by-side promotional/service blocks. The
> user selects their desired service by clicking on one of them.

## Block 1: AI Mock Interview Training (15-Minute Session)

**Workflow:**

1. After clicking the mock interview feature, the user is redirected to the interview page.
2. The interview page features a central video screen (resembling Microsoft Teams or Zoom). Below the screen is a dropdown menu for the user to select the interview language.
3. The user uploads their current CV into a designated box so the AI can analyze it and extract 10 relevant questions.
4. The user enters the target job title they are applying for, allowing the AI to generate 5 additional role-specific questions.
5. The user clicks the "Confirm" or "Next" button.
6. The AI redirects the user to the secure payment gateway (PayPal, Google Pay, Visa). An electronic invoice is issued after successful payment verification. Once completed, the user clicks "Start Interview".
7. The AI mock interview begins with an AI avatar (Male/Female). The avatar asks a total of 15 questions (derived from the CV analysis and job title) over a duration of 15 minutes.
8. Upon completion, the avatar gracefully ends the interview. The interview report is displayed at the bottom of the screen:
   - Questions: Displayed in Black.
   - User Answers: Displayed in Red.
   - Correct/Ideal AI Answers: Displayed in Green.
   - Correct and incorrect answer percentages are also shown.
9. A "Starting Over" button appears, taking the user back to the homepage to repeat the process if desired.

## Block 2: Professional CV Preparation & Career Services

**Workflow:**

1. The user uploads their old CV into the designated area and clicks "Next".
2. The AI directs the user to a new page to select from 10,000 modern CV templates, then clicks "Next".
3. The user selects their preferred language from a dropdown menu containing: English, French, Spanish, Russian, Arabic, Mandarin Chinese, Swedish, German, Italian, Japanese, Korean, Thai, Indonesian, Turkish, Hebrew, Hindi, Portuguese, Urdu, Danish, Norwegian, Ukrainian, Polish, Czech, Slovak, Serbian, Croatian, Bulgarian, and Macedonian. The user clicks "Next".
4. The AI analyzes the uploaded CV and performs the following tasks based on it:
   - Creates a professional CV fully compatible with Applicant Tracking Systems (ATS).
   - Generates tailored Cover Letters.
   - Prepares and optimizes profiles for global platforms (LinkedIn, Indeed, etc.).
   - Optimizes keywords to maximize CV visibility.
   - Highlights skills and experience professionally.
   - Ensures a clean, attractive, and clear layout.
5. The AI redirects the user to a new page to review the generated items. Each file is displayed individually for reading-only purposes (downloading to the device is blocked at this stage). The user clicks "Agree" to proceed.
6. The system redirects the user to the payment gateway (PayPal, Google Pay, Visa). An electronic invoice is issued upon successful payment.
7. Once paid, a button becomes active allowing the user to download all generated files in Word and PDF formats.
8. A "Starting Over" button appears, returning the user to the homepage.

## General Website Notes & Features

- **Live User Counter:** Includes a user counter starting at 50,000 users, which increments dynamically with every completed user payment.
- **Payment Badges:** Displays official payment gateway badges (PayPal, Google Pay, Visa).
- **No Email Registration Required:** The website operates seamlessly without requiring user account sign-up or email registration.
- **Responsive Design:** Fully optimized and responsive for both laptops/desktops and mobile phones.
